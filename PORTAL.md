# PORTAL — AI Coding Guidelines

Entry point for this repository's engineering standards: toolchains, library choices, practices, and agent rules.

**How to use:**

1. Find your task in the reading recipes below and read the listed documents in order.
2. Follow what they say. Standardized tools are mandatory unless the user explicitly approves an exception.
3. Editing this repository itself? Read [AGENTS.md](./AGENTS.md) instead.

> Always trust the files in this repository over remembered summaries.

Languages: [English](./guidelines/en/) · [中文](./guidelines/zh/) · [日本語](./guidelines/ja/)
