AI 编码指南

给 AI Agent 和代码评审者看的工程指南，涵盖工具链、工程实践、技术选型与平台规范，并按任务场景组织阅读顺序。

在项目中使用

安装 skill

在项目目录运行这条命令，然后明确要求 Agent 按本指南执行当前任务。

pnpm dlx skills add fang2hou/ai-coding-guidelines@apply-guidelines

直接交给 AI Agent

也可以不安装 skill，直接把下面的提示词发给 AI Agent。

请按 https://github.com/fang2hou/ai-coding-guidelines 中的指南执行当前任务。
从 PORTAL.md 开始，按任务对应的阅读顺序查阅并应用相关规范。

工具链

9 篇

各语言生态的统一工具链，本地开发与 CI 环境保持完全一致。

  • Databricks对于数据和 AI 工作负载，优先选用 Databricks：用 Databricks Apps 托管和管理应用，用 Databricks Jobs 执行定时或自动任务。
  • Git 工作流所有项目提交必须遵循 Conventional Commits 规范。
  • GitHub ActionsGitHub Actions 是标准 CI/CD 平台；用户未指定流水线系统时，默认选择 GitHub Actions。与工具无关的流水线规则见 流水线。
  • Go 工具链TypeScript 与 Python 是 AI 辅助开发的默认语言。Go 不是默认选项，仅当项目确实需要以下能力时才选择 Go：

  • Python 工具链Python 与 TypeScript 是 AI 辅助开发的默认语言，因为它们的库生态和 AI Agent 生态最成熟。

库与框架

8 篇

前后端、样式与 AI 应用的默认技术栈与选型边界。

  • Agentation视情况采用——在前端迭代和测试期间启用 Agentation，将视觉反馈转换为 AI 编码 Agent 可直接使用的结构化上下文。
  • 前端框架：Vite 与 Next.js首选——Vite 是默认前端框架；只有项目确实需要全栈 React 能力时才选择 Next.js。
  • Go API 技术栈首选——Go Web 框架使用 Echo，请求校验使用 github.com/go-playground/validator/v10。只有依据 Go 工具链 的标准完成 Go 本身的选型论证后，才适用本技术栈。
  • Python API 技术栈首选——FastAPI + Pydantic + Uvicorn 是标准的 Python API 技术栈；三者应作为一个整体采用，而不是分别挑选。
  • Svelte（Svelte 5 + SvelteKit）视情况采用——Svelte 5 加 SvelteKit 允许用于以开发乐趣为目标的小型个人项目和实验项目。它不是默认选择：生产前端仍使用前端框架中选定的 React 技术栈。
  • Tailwind CSS视情况采用——项目已在用 Tailwind，或组件套件依赖 Tailwind 时才使用。新的样式开发默认使用原生 CSS。
  • TypeScript 后端技术栈首选——TypeScript 后端服务使用 Hono。默认运行时为 Node.js Active LTS 版本线；Web 标准 API 使服务可移植到 Cloudflare Workers 等其他运行时。模型根据训练数据生成代码，主流且经…
  • Vercel AI SDK视情况采用——仅当 Next.js 项目确实要用到 Vercel AI SDK 的流式响应或 UI 集成功能时才使用。
