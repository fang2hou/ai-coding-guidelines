# セキュリティ

## 機密情報のコミット禁止

次のようなシークレットや機密情報をリポジトリにコミットしてはならない。

- パスワード
- API キー
- アクセストークン
- 非公開の認証情報
- シークレット
- 機密性の高い接続文字列

## シークレットの保管先

シークレットは適切な場所に保管すること。

- 環境変数
- シークレット管理システム
- デプロイプラットフォームのシークレット機能
- 安全な構成

ローカルのシークレットファイル（`.env` など）は必ずバージョン管理の対象外にする。

## シークレットスキャニング

[品質ゲート](../toolchain/quality-gates.md)にシークレットスキャニングを組み込み、すべての変更について完了前に機密情報の有無を確認すること（[変更の規律](change-discipline.md)を参照）。
