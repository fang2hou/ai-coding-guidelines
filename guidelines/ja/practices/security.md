# セキュリティ

## 機密情報のコミット禁止

リポジトリに機密情報を含めてはならない。

これには、少なくとも次が含まれる。

- パスワード
- API キー
- アクセストークン
- 非公開の認証情報
- シークレット
- 機密性の高い接続文字列

## シークレットの保管先

シークレットの管理には、次の適切な手段を使用すること。

- 環境変数
- シークレット管理システム
- デプロイプラットフォームのシークレット機能
- 安全な構成

ローカルのシークレットファイルがバージョン管理の対象外であることを確認すること。

## シークレットスキャニング

シークレットスキャニングは、プロジェクトの[品質ワークフロー](../toolchain/quality-gates.md)に組み込むべきである。

さらに、すべての変更について、完了前に機密情報の有無を確認しなければならない（[変更の規律](change-discipline.md)を参照）。
