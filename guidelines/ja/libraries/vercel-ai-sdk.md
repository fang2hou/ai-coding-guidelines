# Vercel AI SDK

## 判定

条件付き — Vercel AI SDK は、Next.js 実装で明確な価値がある場合に限って使う。

## 使用する場面

- Next.js の実装が SDK の機能を実際に使う場合。
- 実装する機能が、SDK が具体的に提供する機能（AI レスポンスのストリーミング処理など）に直接対応する場合。

## 避けるべき場面

- アプリケーションに LLM 機能があるだけでは、依存関係を追加する理由にならない。
- すべての AI 関連プロジェクトに SDK を自動追加する場合。
- SDK を利用する Next.js 実装がプロジェクトにない場合。

## 長所

- React と Next.js の UI における AI レスポンスのストリーミング処理を提供する。
- LLM 統合間で、プロバイダーへのアクセス方法とツール呼び出しのパターンを標準化する。

## トレードオフ

- 追加の依存関係であり、その価値は実装が SDK の機能を実際に使うかどうかで決まる。
- 本ガイドラインでの適用範囲は Next.js プロジェクトに限られる。

## バージョン方針

- SDK を使う場合は、最新の安定版を優先する。
- 具体的な互換性の理由がない限り、プロジェクトを古いバージョンに留めてはならない。

## 利用ルール

- Vercel AI SDK は、Next.js プロジェクトで明確な価値がある場合に限って使う。
- すべての AI 関連プロジェクトに自動的に追加してはならない。
- アプリケーションに LLM 機能があるという理由だけで導入してはならない。
