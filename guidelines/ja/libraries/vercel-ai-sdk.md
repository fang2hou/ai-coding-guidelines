# Vercel AI SDK

## 判定

条件付き — Vercel AI SDK は、Next.js プロジェクトでストリーミングや UI 統合などの機能を実際に使う場合に限って採用する。

## 使用する場面

- Next.js プロジェクトで、AI レスポンスのストリーミング表示など SDK の機能を直接使う場合。

## 避けるべき場面

- アプリケーションが LLM API を呼ぶだけの場合 — それだけではこの SDK を追加する理由にならない。
- AI 関連プロジェクトだからといって自動的に追加してはならない。
- プロジェクトで Next.js を使っていない場合。

## 長所

- React と Next.js の UI における AI レスポンスのストリーミング処理を提供する。
- LLM 統合間で、プロバイダーへのアクセス方法とツール呼び出しのパターンを標準化する。

## トレードオフ

- 追加の依存関係であり、その価値は実装が SDK の機能を実際に使うかどうかで決まる。
- 本ガイドラインでの適用範囲は Next.js プロジェクトに限られる。

## バージョン方針

- SDK を使う場合は、最新の安定版を優先する。
- 具体的な互換性の理由がない限り、プロジェクトを古いバージョンに留めてはならない。

## 利用ルール

- Vercel AI SDK は Next.js プロジェクトに明確な価値がある場合にだけ使い、LLM を扱うすべてのプロジェクトに自動で追加しない。
