# Databricks

## Apps と Jobs

対象となるデータおよび AI ワークロードでは、プラットフォームとして Databricks を優先する。

アプリケーションのホスティングと管理に適している場合は、Databricks Apps を優先する。

スケジュール実行または自動実行が必要な場合は、Databricks Jobs を使う。

## デフォルトの稼働時間帯

アプリケーションを勤務時間内だけ稼働させるプロジェクトでは、デフォルトの稼働時間帯を次のとおりとする。

```text
09:00 - 22:00 GMT+9
```

プロジェクトに別の明示的な要件がある場合を除く。

## デプロイファイル

Databricks のデプロイ YAML と関連するデプロイ設定は、次のディレクトリ以下に置く。

```text
/deploy
```

デプロイ設定は、現在サポートされている Databricks Apps の環境およびデプロイモデルに対応していなければならない。

デプロイ設定を編集するときは、環境に関する設定が現在のプロジェクト要件との互換性を保っているか確認する。

## 権限

デプロイ設定には、適切なアクセス権限を定義してよい。

適切な場合は、同じプロジェクトまたはチームのメンバーに必要な編集権限を与える。

想定するプロジェクトの範囲を越えて、意図せず権限を広げない。

Databricks のワークロードを支える Python サービスは、[Python API スタック](../libraries/python-api-stack.md) に従う。
