# セキュリティ

## 機密情報を絶対にコミットしない

リポジトリに機密情報を含めてはならない。

対象は次のものに限られない。

* パスワード
* API キー
* アクセストークン
* 非公開の資格情報
* シークレット
* 機密性の高い接続文字列

## シークレットの置き場所

次の適切な手段を使用すること。

* 環境変数
* シークレット管理システム
* デプロイプラットフォームのシークレット機能
* 安全な設定管理

ローカルのシークレットファイルが、バージョン管理から除外されていることを確認すること。

## シークレットスキャニング

シークレットスキャニングは、プロジェクトの[品質ワークフロー](../toolchain/quality-gates.md)の一部であるべきである。

さらに、すべての変更は、完了前に機密情報の有無を確認しなければならない([変更の規律](change-discipline.md)を参照)。
