# Vercel AI SDK

## 判定

状況限定 — Vercel AI SDK は、Next.js 実装に実際の価値をもたらす場合にのみ使う。

## 使用する場面

- 実際の Next.js 実装が、SDK の能力から恩恵を受ける場合。
- 実装する機能が、SDK が具体的に提供する機能(AI レスポンスのストリーミング処理など)と直接対応する場合。

## 避けるべき場面

- アプリケーションが単に LLM 機能を含むだけの場合 — それだけでは依存関係を追加する理由にならない。
- AI 関連プロジェクトすべてに SDK を自動的に追加すること。
- SDK が恩恵を与えられる Next.js 実装が、プロジェクトに存在しない場合。

## 長所

- React と Next.js の UI に対して、AI レスポンスのストリーミング処理を提供する。
- LLM 統合全体で、プロバイダーアクセスとツール呼び出しのパターンを標準化する。

## トレードオフ

- 追加の依存関係であり、その価値は実装が実際に SDK の能力を使うかどうかで決まる。
- 本ガイドラインでの適用範囲は、Next.js プロジェクトのみである。

## バージョン方針

- SDK を使う場合は、最新の安定版を使う。
- 具体的な互換性の理由がない限り、プロジェクトを古いバージョンに留めてはならない。

## 利用ルール

- Vercel AI SDK は、Next.js プロジェクトに実際の価値をもたらす場合にのみ使う。
- AI 関連プロジェクトすべてに自動的に追加してはならない。
- アプリケーションが LLM 機能を含むという理由だけで導入してはならない。
- 実際の Next.js 実装が SDK の能力の恩恵を受ける場合に使う。
